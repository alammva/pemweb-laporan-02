1. Mengapa menggunakan CSS dan JavaScript dalam pemrograman web modern?

CSS (Cascading Style Sheets) digunakan untuk mengatur tampilan dan layout halaman web, seperti warna, font, margin, dan posisi elemen, sehingga memisahkan struktur (HTML) dari presentasi. JavaScript digunakan untuk menambahkan interaktivitas dan dinamika, seperti menangani event pengguna, validasi form, animasi, dan komunikasi dengan server. Dalam pemrograman web modern, kombinasi keduanya meningkatkan maintainability kode, performa, dan pengalaman pengguna, memungkinkan pengembangan aplikasi web yang lebih kompleks dan responsif.

2. Jelaskan konsep dan tujuan utama dari Responsive Web Design (RWD)!

Responsive Web Design (RWD) adalah pendekatan desain web yang membuat layout halaman web dapat menyesuaikan diri secara otomatis dengan ukuran layar perangkat pengguna, seperti desktop, tablet, atau smartphone. Konsep utamanya melibatkan penggunaan media query, flexbox/grid, dan unit relatif (seperti persen atau em) untuk membuat elemen responsif. Tujuan utamanya adalah memastikan pengalaman pengguna yang optimal di semua perangkat, meningkatkan aksesibilitas, mengurangi kebutuhan pengembangan versi terpisah, dan meningkatkan peringkat SEO karena Google memprioritaskan situs responsif.

3. Bagaimana kombinasi CSS, JavaScript, dan prinsip RWD dapat menghasilkan tampilan web yang interaktif sekaligus adaptif? Jelaskan bagaimana ketiganya saling melengkapi!

CSS menangani styling dan layout statis, seperti mengatur warna, font, dan posisi elemen menggunakan teknik seperti flexbox atau grid. JavaScript menambahkan lapisan interaktivitas dengan menangani event (misalnya klik tombol, validasi input), manipulasi DOM, dan logika dinamis. Prinsip RWD memastikan adaptivitas melalui media query yang menyesuaikan layout berdasarkan ukuran layar. Ketiganya saling melengkapi: CSS menyediakan fondasi visual yang responsif, JavaScript membuatnya interaktif (misalnya mengubah tampilan berdasarkan input pengguna), dan RWD memastikan semuanya berfungsi di berbagai perangkat, menghasilkan web yang tidak hanya menarik dan fungsional tetapi juga adaptif terhadap lingkungan pengguna.
